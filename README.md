# Local Perplexity Clone

Build a local Perplexity-style assistant using Agno, Ollama, and Crawl4AI.

## Features

1. Do web research, including fast search and deeper research workflows.
2. Read files, write files, and analyze file contents with file tools.
3. Run shell commands with shell tools.
4. Run Python code to solve problems with Python tools.

## Goal

The goal of this project is to create a local research assistant that can search the web, inspect files, execute commands, and solve tasks programmatically from a single interface.
